표기법

공통 네이밍 규칙 예
종류 구분 번호 예시
ID Selector 카멜표기법 (camelCase) 한 자리수 (생략가능, 2, 3) errorMesage, controlCenter, controlCenter2
Class Selector 스네이크 표기법 (hyphen-nate) 한 자리수 (생략가능, 2, 3) tab-page, tbl-type1, tbl-type2
Image 스네이크 표기법 (underbar_nate) 두 자리수 (01, 02, 03) btn_cancle01_off.gif
파일 및 폴더 스네이크 표기법 (underbar_nate) 두 자리수 (01, 02, 03) board_list.html

이미지 네이밍 규칙

이미지 예약어
분류 예약어_[상세규칙] 예시
아이콘 icn_[크기]_[이름]_[번호]_[컬러/상세]

컬러/상세는 필요한대로 사용 가능

icn_24_right_01_bk / icn_24_right_01_pr

icn_24_right_01_off / icn_24_right_01_on
배경 bg_[이름]

이름에 넘버링이 포함되면 중복 가능

bg_mn_sec1_01 / bg_main_sec01_01
일반 img_[이름] img_company_01
임시 @[이름]_[번호]

이름은 자유형식이며 @는 반드시 적용한다.

@thumb_sec01_01

@sample_sec01_01
